# Iniyazh Turns TWO — Storybook Website

A mobile-friendly page-turning birthday invitation website.

## Quick start

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Edit `config.js` to add:
   - birthday time
   - WhatsApp number, including country code but no `+`
   - optional Google Form link
4. Replace or add media:
   - `images/hero.jpg` — main princess photo
   - `images/photo1.jpg`, `photo2.jpg`, `photo3.jpg` — gallery photos
   - `videos/invitation.mp4` — invitation video
   - `music/fairytale.mp3` — optional background music

The included hero photo is the image supplied in this chat. Missing gallery images automatically use the hero photo.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload everything inside the `iniyazh-storybook-complete` folder.
3. In the repository, go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`, then save.
5. GitHub will provide a shareable website link.

## Notes

- Browsers require the visitor to tap the music button before audio can play.
- Large videos may exceed GitHub's per-file limit. Compress the MP4 or host it elsewhere and replace the video source URL in `index.html`.
- The design is an original classic fairytale-princess theme and does not contain copyrighted character artwork.
